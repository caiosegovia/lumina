# Lumina 0.24.0-beta.1

Release de estabilização operacional baseada nos diagnósticos reais da 0.23.1.

Principais mudanças: redisparo automático de jobs, recuperação por lease, atividade consciente da fila, caminho RAW eficiente, seleção nativa no Explorer e timestamps de diagnóstico sem ambiguidade de fuso.

Consulte `VALIDATION-0.24-BETA.md` para o roteiro completo. Esta é uma beta homologável; a promoção para estável depende do ensaio prolongado no dispositivo oficial.
